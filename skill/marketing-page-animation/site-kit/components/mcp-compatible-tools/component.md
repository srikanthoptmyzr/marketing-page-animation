# mcp-compatible-tools

Captured verbatim from `component-library/components/mcp-compatible-tools/`.

- Fields used by the template: 5
- Fields with a blueprint default: 9
- **Copy fields not in the translatable-key list:** tools. The script translator (`scripts/translate.js`) matches a field's own key exactly, so it skips these; the LLM localization agent usually translates them anyway. Parity therefore depends on which path runs. Prefer a listed field name for new scene copy, and flag this for the dev team.
